# 审核完成后的改稿衔接（可选）

本技能**默认只产出评审**，不修改 `.tex`。用户要求「按行动清单改稿」时，可参考下列阶段（与 `行动清单.md` 的 P0→P1→P2 对应）：

| 阶段 | 目标 | 建议扮演 |
|------|------|----------|
| **结构重组** | 合并实验子节、重写 Discussion、移除 FAQ、移附录 | 📚 博士生 + ✍️ 编辑 |
| **内容深化** | 精炼贡献、补 SOTA 对比、深化 Limitation、统一数据 | 📚 + 📊 统计 |
| **格式与投稿** | 参考文献、Cover Letter、AI/CRediT 声明 | ✍️ 编辑 |

改稿后建议：**新建 `run_id` 再跑一轮本技能**（Phase 0–5），对比 P0 是否关闭。
