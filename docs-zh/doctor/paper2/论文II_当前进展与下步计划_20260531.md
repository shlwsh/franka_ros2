当前状态应表述为：

| 项目 | 当前结论 |

| 科研阶段 | synthetic MVP + 审计完备的论文初稿 |

| 主要阻塞 | 真实数据、官方 validator、授权标识、真实机器人闭环、真实专家评审 |

## 4. 未完成项与风险分级

| 优先级 | 未完成项 | 当前原因 | 风险 |
|---|---|---|---|
| P0 | 真实公开/受控数据集主实验 | MIMIC-IV-Note 与 MIMIC-CXR 仍为 placeholder，没有本地 no-PHI derived file | 没有真实数据就不能声称临床或公开 benchmark 有效性 |

| P0 | Gazebo/FR3 在线闭环 | 默认离线流程未连接 fake hardware/Gazebo/FR3 API | 不能声称机器人闭环实测完成 |
| P1 | 授权本体标识 | 当前只有 placeholder-only entity map | 不能使用或提交受限 ICD/SNOMED 原文 |
| P1 | 大规模 GNN/GAT | 只有 graph-attention-lite 小型基线 | 不能声称完成真实大图训练 |
| P1 | 多 seed 实验矩阵 | 当前 B0-B4 是单次 deterministic run | 缺少稳定性统计 |
| P2 | Manuscript section split | LaTeX 仍以 monolithic `main.tex` 为主 | 不阻碍 MVP，但影响投稿工程质量 |
| P2 | 专利交底 | 文件缺失 | 非投稿必需，但影响成果保护 |

## 6. 建议执行节奏

### 第 1 轮：本地证据补强

目标：把可本地完成的 partial 项尽量推进到 ready。

建议顺序：

1. 增加 hallucination standalone eval。
2. 增加 multi-seed synthetic matrix。
3. 补 KG gate AUC 或写明替代指标。
4. 创建专利交底草稿。
5. 重跑 `pytest`、closed-loop pipeline、bilingual sync、phase completion audit、readiness audit。

预期收益：阶段完成度可能从 23 ready 继续提升，且论文结果段更稳健。

### 第 2 轮：论文工程化定稿

目标：提高中英文稿件的投稿工程质量。

建议顺序：

1. 拆分 LaTeX `method.tex`、`system.tex`、`results.tex`、`discussion.tex`。
2. 将审计结果转为论文附录表。
3. 同步中文稿、英文稿、LaTeX 和 PDF。
4. 运行 `run_bilingual_sync_audit.py`，确保双语不漂移。

预期收益：形成更接近投稿包的论文结构。

### 第 3 轮：外部实证补齐

目标：把 readiness 中的 required blocked gate 逐个关闭。

建议顺序：

1. 官方 FHIR validator：最容易先形成真实外部验证证据。
2. Gazebo/fake hardware：若本地 ROS 环境可用，优先生成机器人闭环证据。
3. 真实/受控数据：需要审批和仓库外数据路径，周期较长。
4. 授权本体与大图 GNN/GAT：依赖许可证和训练资源。
5. 真实专家评审：依赖专家排期和盲审组织。

预期收益：readiness gate 从 `submission-ready = no` 向投稿级 evidence package 推进。
