样例数据集重放来自 `doctor/paper2/experiments/results/dataset_replay.csv`，使用 `sample_open_csv` no-PHI fixture。24-trial 重放结果为：B0 F1 0.8000、幻觉率 0.5000、FHIR 有效率 0.8333；B4 F1 1.0000、幻觉率 0.1667、FHIR 有效率 0.6667。该结果仅验证数据集桥接和重放逻辑，不代表真实公开数据集结论。

数据集合规审计来自 `doctor/paper2/experiments/results/dataset_compliance_audit.csv` 和 `doctor/paper2/experiments/reports/dataset_compliance_audit_report.md`。当前 registry 中 4 个数据集条目有 2 个 ready、0 个 partial、2 个 blocked；投稿所需 real dataset ready 为 0/2，submission-dataset-ready 为 no。该审计检查 registry 元数据、派生病例 schema、受控数据路径是否在仓库外、基础 PHI 模式风险和审批证据字段；当前 MIMIC-IV-Note 与 MIMIC-CXR 仍只是 controlled placeholder，没有本地派生文件。

训练型 graph-attention-lite 结果来自 `doctor/paper2/experiments/results/graph_attention.csv`。在 24 个 synthetic trial 上，Precision、Recall 和 F1 均为 1.0000，学习到的 support attention 为 -7.7959、contradiction attention 为 6.1827、low-quality attention 为 14.9607。该实验是无外部依赖的小型可训练图基线，不等价于大型真实 GAT/GNN。

实体映射覆盖率来自 `doctor/paper2/experiments/results/entity_map_coverage.csv`。当前 10/10 KG 实体有 project-local 映射，FHIR target 覆盖率为 1.0000；所有 ICD/SNOMED 字段均为 placeholder-only，不包含受限本体原文。

FHIR validator replay 来自 `doctor/paper2/experiments/results/fhir_validator_replay.csv`。该实验导出 120 个 Bundle JSON，并以 `local-structural` 模式批量校验：B0-B3 valid rate 均为 0.7500，B4 valid rate 为 1.0000。外部官方 validator 仍需通过 `PAPER2_FHIR_VALIDATOR_CMD` 接入。

专家评审协议验证来自 `doctor/paper2/experiments/results/expert_review_agreement.csv`。当前为 synthetic placeholder：40 个 review item、2 个 synthetic reviewer、80 条 annotation。factually_supported 和 fhir_acceptable 的 kappa 为 1.0000，needs_human_review 的 kappa 为 0.8961。该结果只验证评审表结构和一致性统计脚本，不代表真实医生评审。

真实专家评审接入入口来自 `doctor/paper2/experiments/run_real_expert_review.py`。该脚本不会生成伪真实标注，只从当前 `review_packet.csv` 输出 `real_annotations.template.csv`，并在真实专家填写 `real_annotations.csv` 后检查至少两名非 synthetic reviewer、review item 与 packet 对齐、布尔字段合法、评分范围为 1-5、每个 item 至少两名 reviewer 覆盖，再生成 `real_expert_review_agreement.csv` 和 `real_expert_review_report.md`。当前尚无真实标注，因此 readiness gate 仍为 blocked。

投稿级前置条件审计来自 `doctor/paper2/experiments/results/readiness_audit.csv` 和 `doctor/paper2/experiments/reports/readiness_audit_report.md`。默认离线复现模式下共有 16 个 gate：ready 6 个、partial 1 个、blocked 9 个；投稿必需 gate 仅 1/11 ready，submission-ready 为 no。该审计把已完成的软件证据与仍缺失的真实数据、官方 validator、授权本体标识、真实大图 GNN/GAT、Gazebo/FR3 闭环和真实专家评审分开记录，防止把 synthetic MVP 误表述为最终科研完成。
