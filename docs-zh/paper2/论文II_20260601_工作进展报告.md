**问题发现**：`run_bilingual_sync_audit.py` 中的 `readiness_counts` 正则模式硬编码了旧数字（18 gate, 8/1/9），与实际 CSV 数据（18 gate, 7/1/10）不匹配，导致审计报告出现 2 个 false blocked 行。

**修复内容**：更新 `doctor/paper2/experiments/run_bilingual_sync_audit.py` 中 `readiness_counts` 的中英文正则模式：

```python

r"18.{0,80}gate...ready...8...partial...1...blocked...9"
# 修复后（正确数字）
r"18.{0,80}gate...ready...7...partial...1...blocked...10"
```

**验证结果**：
