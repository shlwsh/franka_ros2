## 1. 创新地图：MVP 实现 vs 博士方案愿景

博士实施方案（`石洪雷_博士学位论文IIn_SCI一区聚焦科研实施方案_V2.md`）提出了更宏大的 **GN-KGCAD**、**TGD-VAM**、**Toolformer-Med** 等算法。当前 MVP 是其在工程上的**可复现最小核**：

| 博士方案算法 | 完整愿景 | 当前 MVP 对应 | 成熟度 |
|-------------|----------|--------------|--------|
| **GN-KGCAD** | GAT 大图谱嵌入 + 动态 \(\gamma_t\) 熔断 | 规则 \(\gamma_{conflict}\) + signed KG 族 | 🟡 原型 |
| **TGD-VAM** | 文本 Cross-Attention 引导视觉检测 | 规则 lexicon 抽取 + synthetic vision_tags | 🔴 未实现 |
| **Toolformer-Med** | 自监督学习何时调用工具 | 确定性 `decide_route()` 触发工具 | 🟡 路由级 |
| **XAI-MKG** | Grad-CAM + 图谱证据链 | `kg_matches` JSONL 审计 | 🟡 轻量 |
| **ST-AAM** | 时空注意力去模糊超分 | 继承论文 I Edge-IQA 的 `q_img` | 🟢 论文 I 已有 |

> **答辩口径**：MVP 验证的是**算法范式**（门控→路由→工具→校验）可跑通；GN-KGCAD 的 GAT 大图训练是**同范式上的增强**，不是另起炉灶。

## 2. 创新 A1：多模态 KG 冲突门控分数 \(\gamma_{conflict}\)

### 2.1 算法定义

给定主诉实体集 \(E_{text}\)、视觉标签集 \(E_{vision}\)、图像质量 \(q_{img}\)、期望实体集 \(E_{exp}\)，定义：

\[
\gamma_{conflict} = 0.28\,C_{entity} + 0.24\,Q_{vision} + 0.36\,C_{kg} - 0.22\,P_{contradict}
\]

各分量：

| 符号 | 计算 | 代码函数 |
|------|------|----------|
| \(C_{entity}\) | \(\|E_{exp} \cap E_{text}\| / \|E_{exp}\|\) | `entity_completeness()` |
| \(Q_{vision}\) | \(\mathrm{clip}(q_{img}, 0, 1)\) | 继承论文 I Edge-IQA |
| \(C_{kg}\) | \(\mathrm{clip}(s - c + 0.45, 0, 1)\) | `score_kg_consistency()` |
| \(P_{contradict}\) | KG contradicts 边最大权重 | 同上 |

其中 \(s\) = supports 边命中最大权重，\(c\) = contradicts 边命中最大权重。

**设计 rationale**：

- **KG 权重最高（0.36）**：论文 II 的核心科学问题是**跨模态语义冲突**，不是单纯图像质量
- **矛盾项以减号进入**：显式惩罚 text-vision 在 KG 上的 contradicts 边
- **可解释**：每个 trial 的 `kg_matches` 可 JSONL 回溯

### 2.2 与业内方法对比

| 方法 | 代表工作/产品 | 核心机制 | 本文 A1 的差异 |
|------|--------------|----------|---------------|
| **Naive LLM 融合** | Med-PaLM 一次性生成、GPT-4 临床笔记 | 多模态 prompt 拼接 → 直接生成 | 无显式冲突分数；B0 幻觉率 **62.5%** |
| **RAG** | LangChain RAG、MedRAG | 检索相关文档片段注入 prompt | **增强生成**，不**阻止生成**；检索噪声仍可能幻觉 |
| **GraphRAG** | Microsoft GraphRAG | 社区检测 + 子图摘要 → LLM | 解决「知识组织」，非「何时禁止生成」 |
| **Self-RAG** | Asai et al., 2023 | 生成后自评 retrieve/generate/critic | **Post-hoc** 反思；B1 幻觉率仍 **25%** |
| **KG-constrained Decoding** | NeuroLogic、KG-BART | 解码时限制 token 空间 | 约束**词表**，难约束**多模态+具身动作** |
| **Clinical BERT + Rules** | 传统 CDSS 规则引擎 | IF-THEN 临床规则 | 无 LLM/EMR 生成；本文兼容 LLM 占位 |
| **本文 \(\gamma_{conflict}\)** | Paper II MVP | **Pre-generation 可阈值融合分数** | 统一门控 + 可路由 + JSONL 审计 |

**关键论点（必背）**：

> RAG/GraphRAG 回答「生成时用什么知识」；\(\gamma_{conflict}\) 回答「**现在能不能生成**」。这是**生成时机控制** vs **生成内容增强**的本质区别。

### 2.3 消融证据

| 去掉 A1 某分量 | 预期影响 | MVP 验证方式 |
|---------------|----------|-------------|
| 去掉 KG（→ B1） | 幻觉率 0→0.25 | B1 vs B2 对比 |
| 去掉视觉（仅文本） | 低质样本漏检 | case `vision_low_quality` |
| 去掉实体完整度 | 缺实体仍生成 | case `missing_entity` |

## 3. 创新 A2：Pre-Generation Hard Gating（生成前硬门控）

### 3.1 算法定义

路由函数 \(\mathcal{R}(\gamma, baseline)\)：

```text
if baseline == B0:  return generate_emr                    # 无门控
if C_entity < 1.0:  return ask_followup                   # 实体不足
if Q_vision < 0.55: return resample_vision | human_review # 视觉低质
if P_contradict ≥ 0.5: return query_kg                    # 强矛盾
if γ ≥ τ_gating:    return generate_emr                   # 通过门控
else:               return query_kg                       # 未通过
```

阈值：\(\tau_{gating} = 0.65\)，\(Q_{vision}\) 阈值 = 0.55。

**与论文 I 的类比**：

| 论文 I | 论文 II |
|--------|---------|
| \(Q_{img} \geq \tau \Rightarrow\) upload | \(\gamma \geq \tau_g \Rightarrow\) generate_emr |
| \(Q_{img} < \tau \Rightarrow\) resample | \(\gamma < \tau_g \Rightarrow\) query_kg / human_review |

### 3.2 与业内方法对比

| 范式 | 时序 | 代表 | 幻觉路径 | 本文 A2 |
|------|------|------|----------|---------|
| **One-Shot Generation** | 直接生成 | 大多数 EMR Copilot | 冲突样本直接输出 | B0：幻觉 **62.5%** |
| **Post-hoc Verification** | 生成→校验→重写 | Self-RAG, CRAG, Reflexion | 错误文本已产生，靠重写修正 | B1：仍有 **25%** 幻觉 |
| **Pre-generation Gating** | 校验→路由→条件生成 | **本文 B2–B4** | 冲突样本**不进入**生成节点 | B2：幻觉 **0%** |
| **Constitutional AI** | 生成→原则批评→修订 | Anthropic CA | 仍先有一版输出 | 本文避免「先幻觉后修」 |
| **Guardrails / NeMo** | 输出过滤器 | NVIDIA NeMo Guardrails | 拦截**已生成**文本 | 本文在**状态机层**拦截 |

**流程对比图**：

```
【业界 Self-RAG / Reflexion】
  感知 → LLM生成 → 自评 → [不合格] → 重写 → 输出
                    ↑ 幻觉已产生

【本文 A2 Hard Gating】
  感知 → γ门控 → [不合格] → 补拍/补问/查KG → 重新γ
              → [合格]   → EMR/FHIR生成 → 输出
                    ↑ 不合格路径不产生 EMR
```

### 3.3 定量对比（MVP 五基线 = 五种业界范式代理）

| 基线 | 业界对应 | F1 | Hallucination | 机制 |
|------|----------|-----|---------------|------|
| B0 | One-Shot LLM | 0.75 | **0.625** | 无门控 |
| B1 | Self-Reflection | 1.00 | 0.250 | 浅层 post-hoc |
| B2 | **Pre-gen KG Gate** | 1.00 | **0.000** | A1+A2 |
| B3 | + Embodied Recovery | 1.00 | 0.250 | A2+补拍 |
| B4 | + Tool Repair | 1.00 | 0.250 | A2–A5 |

**B2→B3 幻觉回升的解释（答辩必备）**：B3 补拍仅提升 \(Q_{vision}\)，**不消解 text-vision 语义矛盾**；synthetic resample 后 \(\gamma\) 可能仍低但被路由放行——说明**具身自愈必须与 KG 门控联合**，不能单靠图像质量。

## 4. 创新 A3：有符号 KG 评分族（四阶递进）

MVP 实现了从规则到可训练的四阶 KG 评分算法，构成**同一科学假设**（KG 结构可检测跨模态冲突）的不同计算实现：

### 4.1 四阶算法对比

| 阶 | 算法 | 公式/机制 | 复杂度 | 文件 |
|----|------|-----------|--------|------|
| **L0** | 直连边匹配 | \(C_{kg} = f(s, c)\) 在 `compute_conflict_gate` | O(\|E\|) | `kg_conflict_agent.py` |
| **L1** | Signed-Edge Propagation | 一/二跳有符号传播 + 归一化 | O(\|V\|^2) | `run_kg_propagation.py` |
| **L2** | Message-Passing Embedding | one-hot 初始化 → 有符号消息传递 → 余弦相似度 | O(steps·\|E\|) | `run_graph_embedding.py` |
| **L3** | Graph-Attention-Lite | sigmoid(\(w_s S + w_c C + w_q(1-Q) + w_m(1-C) + b_e\)) | O(epochs·n) | `run_graph_attention.py` |

**L1 传播公式（简化）**：

\[
score_{prop} = \frac{direct + \lambda \cdot two\_hop}{\|E_{text}\| \cdot \|E_{vision}\|}
\]

**L3 GAT-lite 学习权重（24 trial 训练后）**：

| 参数 | 值 | 含义 |
|------|-----|------|
| support_attention | -7.80 | 支持边对冲突预测的贡献 |
| contradiction_attention | 6.18 | 矛盾边贡献 |
| low_quality_attention | **14.96** | 图像低质是最强信号 |
| missing_entity_attention | （同报告） | 实体缺失贡献 |

### 4.2 与业内 GNN/KG 方法对比

| 方法 | 代表 | 节点嵌入 | 边类型 | 训练规模 | 本文 A3 |
|------|------|----------|--------|----------|---------|
| **TransE/RotatE** | 知识图谱嵌入 | 平移/旋转 | 单关系 | 大规模 | L2 无训练嵌入 |
| **R-GCN** | Schlichtkrull et al. | 关系卷积 | 多关系 | 大规模 | L1 有符号传播（简化） |
| **GAT** | Veličković et al. | 注意力聚合 | 任意 | 中–大 | L3 lite（线性+logistic） |
| **GraphRAG** | Microsoft | 社区摘要 | 文本图 | LLM 级 | 检索非门控 |
| **MedKG** | 医学 KG QA | SPARQL/子图匹配 | 规则 | ontology | L0 直连（stub 10 实体） |
| **本文 L0–L3** | Paper II MVP | 规则→传播→嵌入→注意力 | support/contradict | **stub 24 trial** | 四阶可审计递进 |

**关键论点**：

1. L0–L3 在 stub 上 F1 均为 **1.0** → 说明**当前数据规模无法区分** GNN 增益，**不能**写「GAT 优于规则」
2. L3 的 `low_quality_attention` 最高 → 与 A1 中 \(Q_{vision}\) 权重 0.24 **一致**，交叉验证视觉质量是冲突检测的重要信号
3. 四阶设计是**向 GN-KGCAD 完整 GAT 的工程桥接**，不是最终算法

### 4.3 与 GraphRAG 的深度对比

| 维度 | GraphRAG | 本文 A3 |
|------|----------|---------|
| **目标** | 改善长文档 QA 的全局理解 | 检测多模态冲突、控制生成时机 |
| **KG 用法** | 社区检测 → 摘要 → prompt | supports/contradicts → \(\gamma\) / 传播分数 |
| **输出** | 增强后的 prompt | 路由决策 + kg_matches 证据 |
| **多模态** | 通常文本 | text + vision tags + q_img |
| **具身** | 无 | resample_vision 工具 |
| **可审计** | 摘要难回溯 | JSONL 每步可追溯 |

## 5. 创新 A4：冲突类型条件化具身自愈路由

### 5.1 算法定义

冲突类型 → 路由 → 工具映射：

| conflict_type | 典型 \(\gamma\) 特征 | 路由 | 工具 | 基线 |
|---------------|---------------------|------|------|------|
| `vision_low_quality` | \(Q_{vision} < 0.55\) | resample_vision | `execute_skill(go_to_tongue_pose)` | B3/B4 |
| `missing_entity` | \(C_{entity} < 1\) | ask_followup | `ask_followup(missing)` | B1–B4 |
| `text_vision_conflict` | \(P_{contradict} \geq 0.5\) | query_kg | `query_kg(matches)` | B2–B4 |
| `fhir_missing` | 结构缺字段 | generate → repair | `repair_fhir` | B4 |

**具身补拍算法（synthetic）**：

```python
q_img_after = min(0.92, q_img_before + 0.34)  # resample_vision()
```

真机版本应调用 `franka_client.execute_skill()`，由 Edge-IQA 重新评分。

### 5.2 与业内 Agent/Tool 方法对比

| 方法 | 代表 | 工具选择 | 路由确定性 | 医疗审计 | 本文 A4 |
|------|------|----------|-----------|----------|---------|
| **ReAct** | Yao et al. | LLM 生成 Thought-Action | ❌ 随机 | 难复现 | ✅ 确定性 `decide_route` |
| **Toolformer** | Schick et al. | 自监督学 API 调用时机 | ❌ 需训练 | 黑盒 | 🟡 规则触发（博士方案 Toolformer-Med） |
| **OpenAI Function Calling** | GPT-4 tools | LLM 选 function | ❌ | 日志不完整 | ✅ 全量 tool_calls JSONL |
| **AutoGen** | Microsoft | 多 Agent 对话 | ❌ | 对话难审计 | ✅ 共享 Paper2State |
| **CrewAI** | 角色分工 | 任务委派 | ❌ | 同上 | ✅ 固定 Agent 职责 |
| **LangGraph** | LangChain | 条件边状态图 | ✅ | 可 checkpoint | ✅ 同范式（MVP 纯 Python 实现） |
| **本文 A4** | B3/B4 | **冲突类型→固定工具** | ✅ | JSONL 逐步审计 | 确定性 + 可消融 |

**与 ReAct 的核心差异**：

```
ReAct:     LLM → "I should call resample" → 执行 → LLM → ...
本文 A4:   γ, Q, C_entity, P_contradict → decide_route() → 固定工具
           ↑ 无 LLM 参与路由决策（MVP）
```

**优势**：B0–B4 可控消融、100% 复现；**劣势**：灵活性低于 LLM 自由 tool-calling（博士方案 Toolformer-Med 拟补齐）。

### 5.3 与论文 I 具身闭环的继承

| 论文 I | 论文 II A4 |
|--------|-----------|
| `resample_edge` | `resample_vision` |
| 触发：\(Q_{img} < \tau\) | 触发：\(Q_{vision} < 0.55\) 或路由策略 |
| Skill：`go_to_tongue_pose` | 同 Skill |
| 闭环：重拍→重新 IQA | 重拍→重新 \(\gamma\) |

## 6. 创新 A5：结构化输出修复闭环（FHIR Repair Loop）

### 6.1 算法定义

```
build_fhir_bundle(omit_observation?) 
  → validate_bundle(mode=local-structural)
  → if invalid and baseline==B4:
       repair_fhir_bundle()  # 补齐 Observation、修复 subject ref
       → validate_bundle() again
```

**本地校验规则**（`validate_fhir_bundle`）：

1. Bundle.type = `document`
2. 首 entry = Composition
3. 含 Patient / Composition / Observation
4. subject.reference 指向 Patient

### 6.2 与业内 FHIR/结构化生成对比

| 方法 | 代表 | 结构化策略 | 校验 | 本文 A5 |
|------|------|-----------|------|---------|
| **Free-text EMR** | 传统 LLM 输出 | 纯文本 | 无 | B0 部分 case |
| **JSON Mode / Structured Output** | OpenAI JSON schema | 约束 JSON 格式 | schema 级 | 不含 FHIR 语义 |
| **FHIR Gen AI** | 各类 FHIR LLM 项目 | prompt 指定 Resource | 少见 | 显式 Bundle 构建 |
| **HAPI Validator** | HL7 官方 | N/A | 完整 Profile | official audit 入口记录命令与 artifact hash |
| **本文 A5** | B4 repair loop | **生成→校验→修复→再校验** | local + official audit gate | FHIR valid 0.25→**0.625** |

**FHIR Validator Replay 结果**（120 Bundle）：

| Baseline | Bundle Valid Rate (local) |
|----------|---------------------------|
| B0–B3 | 0.7500 |
| B4 | **1.0000** |

## 11. 答辩/审稿：算法创新五句话（中英文）

**中文**：

1. 本文核心算法不是更好的 EMR 生成器，而是 **\(\gamma_{conflict}\) 生成前硬门控**——证据不足时不进入生成节点。
2. 相对 Self-RAG/Reflexion 的「生成后反思」，B2 在 synthetic 上将幻觉率从 62.5% 压到 **0%**。
3. KG 以 **supports/contradicts 有符号边**参与门控，而非 GraphRAG 式子图摘要增强。
4. 冲突类型驱动**确定性工具路由**（补拍/补问/查 KG/修 FHIR），优于 ReAct 的 LLM 自由选工具（可复现性）。
5. 四阶 KG 评分族（L0–L3）是向 GN-KGCAD 完整 GAT 的**可审计桥接**；当前 stub 规模下 F1 均为 1.0，需大图谱实验区分增益。

**English**:

1. Our core algorithm is pre-generation KG-gated conflict scoring, not a better one-shot EMR generator.
2. Versus post-hoc self-reflection (B1), hard gating (B2) cuts hallucination from 62.5% to 0% on the synthetic MVP.
3. KG enters as signed support/contradiction edges for gating, not GraphRAG-style subgraph summarization.
4. Conflict-type-conditioned deterministic tool routing improves reproducibility over LLM-free-form ReAct tool selection.
5. The L0–L3 KG scoring family bridges toward full GN-KGCAD GAT; stub-scale experiments cannot yet separate neural vs. rule gains.
