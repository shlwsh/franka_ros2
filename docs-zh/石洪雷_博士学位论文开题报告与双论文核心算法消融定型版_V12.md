**一、 选题背景与研究意义**

### **1.1 研究背景**

随着数字化医疗的深入演进，电子病历（EMR）已成为临床医疗数字资产的核心载体。然而，现行门诊场景下，医生需在极短时间内兼顾口述主诉倾听、面容与舌苔体征视诊观察，以及结构化病历的手动录入。这种高强度的非临床事务性工作极易导致认知过载与漏诊误诊。传统单体软件或刚性工业机器人难以适应诊室高并发网络扰动、医患高频交互、非结构化环境特征。多模态大模型的涌现为语义解析提供了可能，但纯文本 Prompt 模型在长文本长病史问诊中常伴随“信息混淆（Lost in the Middle）”瓶颈。如何将高层语义解析、边缘轻量化计算与低层具身物理伺服深度协同，是实现数字化四诊客观化、量化的关键瓶颈。

### **1.2 研究意义**

本课题兼顾机械工程的物理执行控制与计算机分布式微服务架构思维。通过引入边缘视觉质量评估（Edge-IQA）与 LangGraph 多智能体协同技术，构建“云端大脑-本地小脑”体系。不仅能实现物理采样的硬件无关自适应柔顺控制，还能将自动生成的病历片段定位为数字化生产线全过程的终态数字孪生资产（FHIR 规范）。系统通过高层语义资产提取出的结构化体征数据，能够实时反向驱动机械臂调整伺服位姿，实现自适应主动感知，对于减轻一线医生负荷、提升基层标准化诊疗质量具有重大科学价值。

## **二、 系统总体设计方案（信息物理系统解耦设计）**

系统采用基于工业级高并发网关解耦的**“云-边-端”三层分布式协同架构**，确保各微服务模块的低合性与高可扩展性：

| 层级构型 | 核心技术组件与工具链 | 信息物理系统（CPS）语义与功能   |
| :---- | :---- | :---- |
| **云侧决策大脑层 (Cloud)** | LangGraph 环形状态机、Whisper 语音流 ASR、医疗大语言模型（LLM）、医学知识图谱（KG）、Redis 分布式缓存 | 驱动多智能体集群大脑。编排包含至少 8 个核心状态的有向循环图状态机，执行多模态语义抽取、自愈对冲流转与防幻觉硬校验，完成统一上下文对象（Context Object）的动态分发。 |
| **边侧网关适配层 (Edge)** | Bun 运行时、TypeScript、FastDDS 消息总线、gRPC 跨语言网关、轻量化多帧 Edge-IQA | 运行本地小脑控制回路。建立自适应时间缓冲队列，进行数据预处理、分布式硬时间戳同步与边缘质量判定，拦截低质量数据上传，执行效用控制决策。 |
| **端侧具身执行层 (Device)** | 通用 6-DOF 协作机器人描述模型（参数化 Xacro）、ros2\_control、MoveIt 2、RealSense 深度相机、Rust 安全过滤护栏 | 封装原子能力接口（Skills，如 go\_to\_face\_pose）。无视特定厂商 private 驱动，在本地执行高频硬实时监控、视觉伺服连续轨迹插值，并部署原位锁定失效保护。 |

为确保研究的可落地性与一区学术审查的可复现性，本报告将关键科学问题拆解为 4 项具备精确算法命名的核心创新点，完全基于公开数据集与软件仿真开展对比消融：

| 科学问题 | 提炼的核心算法命名 | 可支撑的国际公开数据集 | 预期对比与消融实验方案   |
| :---- | :---- | :---- | :---- |
| **1\. 分布式异构总线协同下的多模态物联数据流时空硬同步机理** | **EBQ-TSA 算法** (弹性时间缓冲队列与自适应截断时间戳对齐算法) | TCM-Tongue (面舌视觉集) MedQA / PubMedQA (对话语料库) | 注入高斯分布的网络延迟（0\~500ms）与丢包率干扰（0%\~30%）。对比流式直接接入，测试采用 EBQ-TSA 后异构网络环境下多模态时间戳对齐吞吐率，量化评估往返时延（RTT）分布极限。 |
| **2\. 非结构化敏感环境下作业流自愈生成与多Agent语义防幻觉收敛机理** | **GN-KGCAD 算法** (基于图神经网络增强的多智能体冲突自适应对冲与状态流转自愈算法) | OpenAI Med-PaLM / MultiMedQA 评测集 ICD-11 / SNOMED CT / HL7 FHIR 官方本体库 | 人为从数据集中抽取并故意设计主诉文本与视觉特征相互悖论的干扰对（如高热配正常舌苔）。消融对比无回溯线性模式、普通循环模式与 GN-KGCAD 算法下的电子病历 F1-score、Rouge-L 及事实幻觉率。 |
| **3\. 具身智能框架下语义质量标签对异构硬件控制流的反向伺服控制律** | **SE-SAM 控制律** (语义特征映射与硬件抽象层边缘自适应自愈控制律) | Open Robotics 社区公开的 **ros2\_control\_demos** 通用机样参数库 | 在边侧集成 Edge-IQA，若质量未达标则在边侧直接产生齐次变换矩阵。在 Webots 中通过更换 YAML 配置文件改变虚拟机器人的关节限制和连杆臂长（模拟异构硬件本体），绘制跨平台末端跟踪误差一致性曲线。 |
| **4\. 诊室异构光源与活体不确定性环境下的边缘视觉感知前处理机理** | **ILN-Diff 算法 & SAM-SAM 算法** (光照自适应归一化条件扩散模型 & 具身提示词引导多层级语义精细分割算法) | LIME-Dataset (极端低光照集) Bio-Medical SAM 基准 / Tongue-Segment-2024 | 叠加非均匀光照、阴影遮挡与边缘微动。对比传统 Retinex 色彩增强与常规 U-Net、YOLO-seg 分割。引入机械臂正向运动学广播的相机末端位姿作为先验几何提示词，量化评估平均交并比（mIoU）与色彩相似度。 |
