## 日志格式

### Shell 层（`scripts/paper1_log_lib.sh`）

```
[2026-05-31 10:33:26] [INFO] ===== STEP 6/10: Main matrix =====
[2026-05-31 10:33:26] [INFO] RUN script=experiments/run_matrix_tcm.py interpreter=.venv/bin/python args=
```

### Python 层（`doctor/paper1/paper1_trace.py`）

```
2026-05-31 10:33:26 | INFO | paper1.run_matrix_tcm | run_matrix_tcm.py:420 | main | main config=...
2026-05-31 10:33:27 | INFO | paper1.run_matrix_tcm | run_matrix_tcm.py:295 | run_seed | ENTER run_seed | called_from=... | args=(...) | kwargs={...}
2026-05-31 10:39:11 | INFO | paper1.run_matrix_tcm | run_matrix_tcm.py:409 | run_seed | run_seed baseline=B0 seed=0 metrics={...}
2026-05-31 10:40:00 | INFO | paper1.roi_ablation | roi_ablation.py:58 | score_cohort | PROGRESS score_cohort[tongue_roi] 50/572 (8.7%)
```

字段含义：

| 字段 | 说明 |
|------|------|
| 时间戳 | `%Y-%m-%d %H:%M:%S` |
| 级别 | INFO / ERROR |
| 模块名 | `paper1.<脚本名>` |
| 文件:行号 | 当前日志调用位置 |
| 函数名 | `funcName` |
| ENTER/EXIT | 装饰器记录入参、返回值 |
| PROGRESS | 长循环每 N 步输出进度（`log_progress`） |

## 环境变量

| 变量 | 默认 | 说明 |
|------|------|------|
| `PAPER1_LOG_FILE` | 由脚本设置 | Python 追加写入同一日志文件 |
| `PAPER1_TRACE` | `1` | 启用 Python 追踪 |
| `PAPER1_TRACE_FRAMES` | `0` | 设为 `1` 时记录每一帧 `simulate_frame`（日志极大） |

## 已知问题修复（2026-05-31）

`paper1_run_tcm_full.sh` 第 20 行曾报错 `e_iqa/calibrate_tau_b3.py: No such file or directory`：

- **原因**：未加引号的 `experiments/edge_iqa/...` 在部分环境下可能被 bash 错误拆词（`$edg` 等）。
- **修复**：使用 `readonly EDGE_IQA_DIR='experiments/edge_iqa'` + 引号路径；τ_B2 与 τ_B3 分为 step 3a/3b。
