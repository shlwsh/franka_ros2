## 2. 后端实现

### 2.1 核心模块文件

| 文件 | 职责 |
|------|------|
| `src/paper-forge/types.ts` | 类型定义 (PaperProject, ReviewReport, PaperPhase 等) |
| `src/paper-forge/store.ts` | PostgreSQL CRUD (paper_projects, paper_reviews 表) |
| `src/paper-forge/tools.ts` | 论文文件操作 (扫描、读写、全文收集、引用验证、字数统计) |
| `src/paper-forge/agents.ts` | 7 角色 Agent 的系统提示词和配置 |
| `src/paper-forge/orchestrator.ts` | 编排器 (管理评审→修改→再评审循环) |
| `src/paper-forge/index.ts` | 模块统一导出 |
| `src/routes/paper-forge.ts` | Hono 路由定义 (REST + SSE) |

### 2.2 智能体角色

| 角色 | ID | 图标 | 审稿语言 | 最终输出 |
|------|----|------|---------|---------|
| 学术导师 (PI) | `pi-agent` | 🎓 | 中文 | 中文 + 英文修改 |
| 博士生研究员 | `student-agent` | 📚 | 中文 | LaTeX (英文) |
| 统计分析师 | `statistician-agent` | 📊 | 中文 | 中文 |
| 学术编辑 | `editor-agent` | ✍️ | 中文 | 中文 + 英文修改 |
| 审稿人 A (方法论) | `reviewer-agent-1` | 🔍 | 中文 | JSON (中文) |
| 审稿人 B (领域) | `reviewer-agent-2` | 🔬 | 中文 | JSON (中文) |
| 伦理审查员 | `ethics-agent` | 📐 | 中文 | JSON (中文) |

### 2.3 评审循环流程

```
执行一轮评审 (executeReviewRound):
  1. 收集论文全文 (collectFullPaper)
  2. 审稿人 A 评审 → 产出 JSON 评审报告
  3. 审稿人 B 评审 → 产出 JSON 评审报告
  4. 伦理审查 → 产出合规检查报告
  5. PI 综合评审 → 综合各方意见
  6. 计算综合决定 + 检查收敛条件
  7. 更新项目状态

收敛条件:
  - 所有审稿人平均评分 ≥ 7/10
  - 所有审稿人决定 ∈ {accept, minor_revision}
  - 伦理审查通过
  - 或已达最大轮次 (默认 3, 可配置)
```

### 2.4 数据库模型

```sql
paper_projects:
  id, title, paper_dir, current_phase, review_round,
  max_review_rounds, status, metadata, created_at, updated_at

paper_reviews:
  id, project_id (FK), round_number, reviewer_id, decision,
  scores (JSONB), major_issues (JSONB), minor_issues (JSONB),
  strengths (JSONB), full_report (TEXT), created_at
```

## 4. 部署与使用

### 4.1 启动服务

```bash
cd services/agent-platform
bun run dev
# Paper Forge 路由自动挂载在 /api/paper-forge
```

### 4.2 创建论文项目

```bash
curl -X POST http://localhost:3000/api/paper-forge/projects \
  -H "Content-Type: application/json" \
  -d '{"paperDir": "/home/ros/work/paper1/doctor/paper1"}'
```

### 4.3 前端访问

浏览器打开 `http://localhost:5173/paper-forge`

## 5. 用户确认事项

| 项 | 决定 |
|----|------|
| 评审轮次上限 | **3 轮** (可在创建项目时配置 `maxReviewRounds`) |
| 审稿意见语言 | **中文审稿**，所有 Agent 输出使用中文 |
| 最终论文修改 | **LaTeX 英文**，保持原论文语言 |
| LLM 模型 | DashScope `deepseek-v3` (通过环境变量可切换) |
