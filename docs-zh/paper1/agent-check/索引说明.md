## 产出路径（实现后）

审核运行结果默认写入：

```
doctor/paper1/reviews/{run_id}/
├── review-report-{timestamp}.md
├── action-plan.md
├── executive-summary.md
└── round-1/ … dialogue/ … synthesis/
```

环境变量：`PAPER1_ROOT`（默认 `doctor/paper1`）。

**启动审核**（任选其一）：

- 在 Cursor 中对 AI 说「**执行 Paper I 多角色审核**」
- 使用项目技能 **`paper1-multi-agent-review`**

**可移植技能包（开箱即用，推荐复制到其他仓库）**：

```
.cursor/skills/paper1-multi-agent-review/
├── SKILL.md              # Cursor 入口
├── README.md             # 安装说明
├── config.md             # PAPER1_ROOT 配置
├── 设计方案.md / 角色定义手册.md / 已知问题清单.md / …
```

无需启动 Paper Forge 服务。移植时复制整个 `paper1-multi-agent-review` 文件夹并修改 `config.md` 即可。
