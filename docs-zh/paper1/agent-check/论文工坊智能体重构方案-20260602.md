# Paper Forge 智能体独立化重构方案与任务清单

> **日期**: 2026-06-02
> **版本**: v2.0
> **前置文档**: [论文工坊技术实现方案.md](./论文工坊技术实现方案.md) | [多智能体协作论文生产系统设计.md](./多智能体协作论文生产系统设计.md)
> **目标**: 将 `paper-forge/agents.ts` 中的 7 个简陋角色配置，按照项目 `workspaces/` 架构重构为 9 个独立智能体，并实现论文迭代+新论文生成的调度能力。

---

## 1. 重构动机

### 1.1 当前问题

| 问题 | 描述 |
|------|------|
| 角色定义扁平 | 7 个角色以静态数组定义在单一 `agents.ts` 中，仅含 systemPrompt 文本 |
| 无独立人格体系 | 缺少 `SOUL.md`、`AGENTS.md`、`IDENTITY.md` 等标准人格文件 |
| 无工具挂载 | 角色没有独立的 skills 工具，无法执行文件操作 |
| 不通过平台架构 | 直接 `new ChatOpenAI()` 调用，未利用 `AgentRegistry.createAgent()` |
| 缺少论文生成能力 | 只有评审→修改循环，无从创意生成论文的能力 |
| 缺少独立编排器 | 编排逻辑硬编码在 TypeScript 中，非独立智能体 |

### 1.2 目标架构

- 每个角色成为独立的工作空间智能体 (`workspaces/pp-{name}/`)
- 统一加 `pp-` 前缀（Paper Paper）区分
- 通过 `pp-orchestrator` 编排器智能体按需调度
- 支持两种工作模式：迭代已有论文 + 从创意生成新论文
- 复用平台已有的 `AgentRegistry`、工作空间加载、技能挂载机制

## 4. 技能设计

### 4.1 pp-paper-scan（论文扫描）

封装现有 `tools.ts` 中的 `scanPaperDir` + `collectFullPaper` + `countPaperWords` + `validateReferences`。

**输入**: `{ paperDir: string }`
**输出**: 论文目录结构 + 全文内容 + 字数统计 + 引用检查报告

### 4.2 pp-paper-read（论文读取）

封装 `readPaperFile`，支持按路径读取 .tex/.bib 文件内容。

**输入**: `{ paperDir: string, filePath: string }`
**输出**: 文件内容文本

### 4.3 pp-paper-write（论文写入）

封装 `writePaperFile`，支持创建/修改 .tex/.bib 文件。

**输入**: `{ paperDir: string, filePath: string, content: string }`
**输出**: 写入成功确认

### 4.4 pp-phase-control（阶段控制）

与 `PaperForgeStore` 交互，管理项目状态。

**输入**: `{ projectId: string, action: "get" | "advance" | "rollback" }`
**输出**: 当前项目状态

## 5. 编排器重构

### 5.1 当前方式（待废弃）

```typescript
// orchestrator.ts — 硬编码方式
const role = AGENT_ROLES.find(r => r.id === "reviewer-agent-1")!;
const response = await this.callLLM(role.systemPrompt, prompt);
```

### 5.2 新方式

```typescript
// orchestrator.ts — 通过 AgentRegistry 创建独立智能体
const reviewerAgent = await this.registry.createAgent("pp-reviewer-method");
const response = await reviewerAgent.invoke({
  messages: [{ role: "user", content: prompt }],
}, { configurable: { thread_id: threadId } });
```

### 5.3 新增方法

- `executeGeneration(idea, outputDir, onEvent)` — 从创意生成论文
- 保留并重构 `executeReviewRound()` 和 `executeRevision()`
