# 论文工坊 — 论文上传评审与合并输出方案

> **版本**: v0.3  
> **日期**: 2026-06-02  
> **状态**: 实现方案

---

## 1. 需求概述

| 需求项 | 说明 |
|--------|------|
| 论文文件属性 | 项目编辑时可指定/上传待评审论文文件（PDF/LaTeX） |
| 文件上传 | 上传后存入项目的 `uploads/` 目录 |
| 多角色分工评审 | 由论文调度智能体分派各角色依次评审 |
| 合并评审报告 | 所有智能体评审意见智能合并为一份文档 |
| 带时间戳输出 | 输出为 `review-report-{timestamp}.md` |
| 文件下载 | 前端可直接下载评审报告 |

## 2. 数据模型变更

### 2.1 PaperProject 扩展

在 `metadata` JSONB 中新增 `paperFile` 字段（无需 DDL 变更）：

```typescript
// metadata.paperFile
interface PaperFileInfo {
  originalName: string;   // 原始文件名: "main-zh.pdf"
  uploadedPath: string;   // 相对于 paperDir 的路径: "uploads/main-zh.pdf"
  uploadedAt: string;     // 上传时间 ISO
  mimeType: string;       // "application/pdf" | "text/x-tex"
  sizeBytes: number;      // 文件大小
}
```

### 2.2 UpdateProjectPayload 扩展

前端 API 增加 `paperFile` 字段（字符串，记录文件名）。

## 3. 后端 API 设计

### 3.1 论文文件上传

```
POST /api/paper-forge/projects/:id/upload
Content-Type: multipart/form-data
Body: file (论文文件 PDF/TeX)

Response: {
  success: true,
  data: {
    originalName: "main-zh.pdf",
    uploadedPath: "uploads/main-zh.pdf",
    sizeBytes: 343040
  }
}
```

- 自动创建 `{paperDir}/uploads/` 目录
- 将文件保存到该目录
- 更新 `project.metadata.paperFile`

### 3.2 启动论文评审（增强已有接口）

```
POST /api/paper-forge/projects/:id/review
```

增强逻辑：
- 评审完成后，自动调用 `mergeReviewReport()` 生成合并报告
- 输出 `{paperDir}/uploads/review-report-{YYYYMMDD-HHmmss}.md`
- SSE 事件中推送报告路径

### 3.3 文件下载

```
GET /api/paper-forge/projects/:id/download?path=uploads/review-report-xxx.md
```

- 校验路径在 `paperDir` 范围内（防路径穿越）
- 返回文件内容，`Content-Disposition: attachment`

### 3.4 评审报告列表

```
GET /api/paper-forge/projects/:id/reports
```

- 列出 `{paperDir}/uploads/review-report-*.md` 文件

## 4. 评审合并逻辑

编排器 `executeReviewRound()` 完成后，调用新的 `mergeReviewReport()` 方法：

```
输入: ReviewReport[] (各智能体的评审结果)
输出: Markdown 文档

模板:
  # 📄 论文评审报告
  > 论文: {title}
  > 评审轮次: 第 {round} 轮
  > 评审时间: {timestamp}
  > 评审智能体: {agents list}
  
  ## 📊 评分汇总
  | 维度 | 审稿人A | 审稿人B | PI | 平均 |
  
  ## 🎯 综合决定: {decision}
  
  ## 🔍 各审稿人详细意见
  ### 审稿人 A — 方法论审查
  #### 主要问题
  #### 次要问题
  #### 优点
  
  ### 审稿人 B — 领域审查
  ...
  
  ## 📝 合并问题清单（去重）
  ### 主要问题
  ### 次要问题
  
  ## ✅ 修改建议优先级排序
```

## 7. 安全约束

- 文件上传大小限制: 50MB
- 允许文件类型: `.pdf`, `.tex`, `.md`, `.txt`
- 路径穿越防护: 下载接口校验 `realpath` 在 `paperDir` 范围内
- 文件名清理: 替换特殊字符，保留安全文件名
