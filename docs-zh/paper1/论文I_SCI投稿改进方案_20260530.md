## 3. 改进 1（P0）：物理 Skill 响应重采 — 取代随机 Uplift

### 3.1 设计原则

> **Physical-parameter-driven state migration**（物理参数驱动状态迁移）：  
> 重采后的 $Q_{\mathrm{img}}$ 必须来自**对图像施加与 Skill 等价的确定性变换后重新打分**，禁止直接 `q += random`。

### 3.2 新增 Skill 定义（API + 离线同构）

| Skill 名 | 触发 flags | 物理含义（实机） | 离线重放等价变换 |
|----------|-----------|------------------|------------------|
| `adaptive_visual_damping` | `blur` | 降低末端速度 / 短停稳再拍 | 模糊半径 $r \leftarrow \max(r_{\min},\, r \cdot \alpha)$，$\alpha \in [0.4,0.6]$ |
| `exposure_loop_tuning` | `underexposed` / `overexposed` / `poor_exposure` | 环光 PWM / 相机增益步进 | 灰度仿射 $I' = \mathrm{clip}(a \cdot I + b)$，$(a,b)$ 由 flag 查表 |
| `recentre_tongue_roi` | 多次 blur 失败 | 微调 `go_to_tongue_pose` 关节偏移 | 离线：换同 patient 另一张 clear 原图（若有）或 ROI 平移 $\pm$5% |

**配置落点**：`doctor/paper1/experiments/configs/resample_physics.yaml`（新建）

```yaml
# 示例结构
blur:
  alpha_range: [0.4, 0.6]      # 每次重采 blur 半径乘子
  r_min: 1.0
exposure:
  underexposed: {gain: 1.25, bias: 0.08}
  overexposed:  {gain: 0.85, bias: -0.05}
  poor_exposure: {gain: 1.10, bias: 0.03}
max_retries: 2
```

### 3.3 代码改造清单

| 文件 | 动作 |
|------|------|
| **新建** `doctor/paper1/sim/resample_physics.py` | `apply_skill(raw_bytes, flags, retry_idx, meta) -> bytes` |
| **新建** `doctor/paper1/experiments/edge_iqa/synthetic_degrade.py` | 统一 blur / exposure 退化与逆变换（供标定与矩阵共用） |
| **修改** `experiments/run_matrix_tcm.py` | `frame_plan` 存 `raw_bytes, blur_radius, exposure_meta, flags_init`；`resample_edge` 分支调用 `apply_skill` + 重新 `score_*` |
| **修改** `langgraph_router/graph.py` | `resample_edge` 节点输出 `skill_invoked` 字段进 JSONL |
| **修改** `franka_api_server/routers/motion.py` | 注册 `adaptive_visual_damping` / `exposure_loop_tuning`（可先 stub + 日志） |
| **修改** LaTeX `04_2_routing.tex`, `05_11_walkthrough.tex` | 删除 $U(0.15,0.35)$ 表述，改为 Skill–Transform 公式 |

### 3.4 离线重采算法（伪代码）

```python
def resample_score(raw, flags, retry, meta, scorer):
    """替代 q += uniform(0.15, 0.35)"""
    img = raw
    if 'blur' in flags:
        r_new = max(cfg.r_min, meta.blur_radius * rng.uniform(*cfg.alpha_range))
        img = gaussian_blur(img, r_new)
        meta.blur_radius = r_new
    elif 'underexposed' in flags or 'overexposed' in flags:
        params = cfg.exposure[pick_flag(flags)]
        img = affine_brightness(img, **params)
    else:
        img = gaussian_blur(img, meta.blur_radius * 0.5)  # 默认减 blur
    return scorer(img), meta
```

### 3.5 预期实验影响（诚实预测）

| 指标 | 随机 Uplift（现） | 物理 Skill 模型（预期） |
|------|-------------------|-------------------------|
| B2 M2 | 1.000 | **0.85–0.98**（取决于 $\alpha$ 与 $K$） |
| B2 M3 | ~0.44 | 可能略升 |
| 审稿可信度 | 低 | **高** |

> **写作策略**：若物理模型 M2 < 1.0，在 Discussion 中强调 **honest bound**，并报告 **oracle 上界**（直接用 clear 原图重拍）与 **物理模型** 之间的 gap——这比 M2=1.0 更有学术信用。

## 4. 改进 2（P0）：B3 标定 + Hybrid Edge Gating

### 4.1 新增 `calibrate_tau_b3.py`

**路径**：`doctor/paper1/experiments/edge_iqa/calibrate_tau_b3.py`

**逻辑**（与 `calibrate_tau_tcm.py` 对称）：

1. 遍历 val 572 张 ×（clear + synthetic blur）
2. 用 `learned_b3.score_bytes` + ROI 打分
3. 统计 median_clear / median_blur → $\tau_{B3}$（clamp [0.45, 0.65]）
4. 输出 `experiments/results/recommended_tau_b3.json`
5. 附加 ROC / PR 曲线 → `figures/fig_b3_roc.pdf`

**预期**：$\tau_{B3}$ 很可能 **≠ 0.465**（可能在 0.55–0.75 区间，视 softmax 校准而定）。

### 4.2 主表扩展：Table II → Table II + III

| 表 | 内容 |
|----|------|
| **Table II**（不变基线） | B0–B2，$\tau = \tau_{\mathrm{B2}}$ |
| **Table III**（新增） | B3@$\tau_{B2}$ vs B3@$\tau_{B3}$ vs **B4 Hybrid** |

**B4 Hybrid 路由逻辑**（新基线，论文第二技术点）：

```
if flags ∩ {underexposed, overexposed, poor_exposure} ≠ ∅:
    q_gate, τ = Q_B2, τ_B2          # Tier-A：O(HW) 曝光语义
elif retry_count == 0:
    q_gate, τ = Q_B2, τ_B2          # 首帧快速筛
else:
    q_gate, τ = Q_B3, τ_B3          # Tier-B：重采后 blur 精辨
decision = route(q_gate, retry, τ, K)
```

**实现**：`doctor/paper1/langgraph_router/hybrid_route.py` + `run_matrix_tcm.py` 增加 `B4` baseline。

## 附录 B：审稿人 FAQ 预演（投稿 Cover Letter 可用）

**Q1: Why is M2 < 1.0 after revision?**  
A: We removed stochastic score inflation and resample only via flag-conditioned image transforms that mirror on-robot skills; M2 reflects honest recoverability within K=2.

**Q2: Why both B2 and B3?**  
A: Tier-A (Edge-IQA) supplies O(HW) exposure semantics; Tier-B (MobileNet) disambiguates motion blur after resampling—Hybrid B4 combines both.

**Q3: Does offline replay replace robot experiments?**  
A: No. ShezhenV3 provides algorithmic scale; Franka M6 (n=50) bounds local overhead. We explicitly separate CSVs.
