## 必背一句话（电梯演讲）

> 我们在 FR3 机器人舌象采集场景中，提出 **Edge-IQA**（边侧图像质量评估）和 **LangGraph 置信度感知路由**：清晰帧上传云端，模糊帧在边侧重拍。离线主实验显示，相比 naive 全上传（B0），本文方案（B2）将**有效帧率从 50% 提升到 99%**，**中位 RTT 从 397.6 ms 降到 364.7 ms**；Franka 辅轨 50 trial 验证了路由在真实执行链路上可复现。
