## 1. 主实验 Table II / III（必背 · 全量）

> **2026-05-31 全量 + 2026-06-03 改稿**：以下为 **3 seeds × 500 帧** 全量结果（物理 Skill 重采，ShezhenV3 test）。  
> 来源：`main_seed{0,1,2}.csv`、`table_ii.json`；复现：`bash scripts/paper1_run_tcm_finish.sh`。

### 1.1 全量主矩阵（3-seed 均值）— Table II + III

| Baseline | M1 p50 (ms) | M1 p95 (ms) | M2 有效帧率 | M3 重拍率 | 说明 |
|----------|-------------|-------------|-------------|-----------|------|
| **B0** | 374.0 | 656.9 | **0.560** | 0.000 | naive 全上云 |
| **B1** | 322.7 | 534.1 | 0.560 | 0.000 | 无重采 |
| **B2** | **208.3** | **526.9** | **0.604** | **0.440** | **主 claim** |
| B3 @ τ_B2 | 345.6 | 606.8 | 0.934 | 0.481 | MobileNet |
| B3t @ τ_B3 | 341.4 | 609.6 | 0.929 | 0.481 | τ_B3=0.5 |
| **B4** | 343.1 | 617.7 | **0.936** | 0.440 | Hybrid |

### 1.2 核心结论（三句话，全量版）

1. **B2 vs B0**：M2 0.560 → **0.604**；M1 p50 374 → **208 ms**（约 44% 降幅）
2. **B2 vs B1**：重采闭环带来 M2 提升（B1 与 B0 同为 0.560）
3. **B2 vs B3/B4**：学习型 M2≈**0.93** 更高，但 M1 高约 **135 ms**；主 claim 仍为可解释、低延迟 **B2**

## 3. 图表逐张解读

> **编号以英文稿 `main.pdf` 为准**（2026-06-03 编译）。旧版手册中的 Fig.5–7 编号已顺延。

### Fig.1 — 系统架构总览（§3）

- **内容**：云–边–端三层 + Edge-IQA + LangGraph
- **路径**：`doctor/paper1/figures/fig1_system_overview.svg`
- **导师可能问**：「IQA 为什么在边侧不在云侧？」
- **答**：边侧实时约束（< 30 ms）；避免无效上行占带宽；不进 1 kHz 控制循环

### Fig.2 — 路由决策流程（§4.2）

- **内容**：capture → edge_iqa → route 三分支
- **路径**：`figures/fig2_routing_flow.pdf`
- **要点**：条件边显式；重拍后回到 capture 形成闭环

### Fig.3 — Edge-IQA 分数直方图（§5.2 Validation，2026-06-03 前置）

- **内容**：清晰/模糊 cohort 的 Q_img 分布，τ=0.465（ROI）分界线；**两峰重叠**
- **路径**：`figures/fig_iqa_hist.pdf`
- **要点**：`separation_min_clear_max_blur = −0.541`；不声称完美可分，衔接 B3/B4 必要性
- **导师可能问**：「既然重叠，τ 还有意义吗？」
- **答**：τ 是组中位数折中；路由效果看 M2/M1 + 分层 M2；学习对照补盲区

### Fig.4 — RTT 累积分布 CDF（§5.3 Main, M1）

- **内容**：B0–B4 的 RTT CDF 曲线
- **路径**：`figures/fig5_rtt_cdf.pdf`
- **图注关键词**：**simulated latency model**（仿真延迟，非实机 WAN 实测）
- **解读**：B2 曲线整体左移 → 更多 trial 在低延迟区完成
- **Takeaway**：边侧过滤+重拍减少了不必要的云端往返

### Fig.5 — 有效帧率柱状图（§5.3 Main, M2）

- **内容**：各 baseline 的 M2，误差棒 = 3 seeds 标准差
- **路径**：`figures/fig6_valid_rate.pdf`
- **图注关键词**：**simulated latency model**
- **解读**：B0/B1 约 **56%**；B2 约 **60%**；B3/B4 约 **93%**（全量 3 seeds）

### Fig.6 — M2–M1 Pareto 权衡（§5.3 Main，2026-06-03 新增）

- **内容**：B0–B4 及 NR-IQA 的 M2 vs M1 p50 散点
- **路径**：`figures/fig7_pareto_m2_m1.pdf`
- **解读**：B2 左下（低 RTT、中等 M2）；B3/B4/Bniqe 右上（高 M2、高 RTT）
- **Takeaway**：部署选 B2；高有效帧率场景选 B4 或 B3

### Fig.7 — τ 消融实验（§5.4 Ablation, M4）

- **内容**：5 档 τ 下的有效帧率 vs RTT p50 双轴图
- **路径**：`figures/fig7_ablation_tau.pdf`
- **解读**：τ 扫描在验证/测试帧上；峰值附近与 τ_B2≈0.465 一致
- **数据**：`experiments/results/ablation_tau.csv`

### Fig.8 — 失败模式示意（附录，2026-06-03 新增）

- **内容**：清晰 vs 合成模糊注入 ROI _crop 对照（脱敏）
- **路径**：`figures/fig_failure_modes_schematic.pdf`
- **要点**：说明 test 集 blur 注入协议，不与临床真实失败一一对应

### Fig.S1 — Franka 辅轨 RTT（附录, M6）

- **内容**：50 trial 边侧本地回路 RTT 分布
- **路径**：`figures/fig_s1_franka_rtt.pdf`
- **数据**：p50=7.38 ms，p95=8.39 ms，mean=7.55 ms
- **要点**：验证路由决策在真实执行栈可复现；**不与 Table II 数字混比**

## 6. 四条架构边界 + 仿真 RTT 披露（导师高频）

| 原则 | 验证 |
|------|------|
| 算法不进 ROS 包 | edge_iqa/langgraph_router 在 `doctor/paper1/`，API 子进程调用 |
| PAPER1_MODE 禁用阻抗 | `/controller/*` → HTTP 404 |
| 主实验数字来自离线矩阵 | Table II/Fig.4–6 来自 `run_matrix_tcm.py` + **仿真延迟模型** |
| Franka 仅辅轨 | M6 独立 JSONL + Fig.S1，不进 Table II |
| M1 为仿真 RTT | capture 5 ms + IQA N(9,2²) + 云 50–550 ms + 重采 log-normal；见 `sim/NETEM.md` |

## 7. 统计方法（一句话）

≥3 seeds × 500 帧/baseline/seed；报告 mean±std；Table II 表注含帧级 bootstrap 95% CI（B0–B2）；分层 M2 按 clear-source / blur-injected cohort 合并统计。
