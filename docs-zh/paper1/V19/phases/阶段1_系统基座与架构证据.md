## 4. 验收命令

```bash
cd /root/work/franka_ros2
source install/setup.bash
export PAPER1_MODE=1
bash scripts/check_paper1_env.sh

# skills（需 testall 或 start.sh 已起栈）
curl -s -X POST "http://127.0.0.1:8000/api/v1/motion/skills/go_to_tongue_pose?api_key=$FRANKA_API_KEY" | jq .

# vision 占位
curl -s -X POST "http://127.0.0.1:8000/api/v1/vision/evaluate?api_key=$FRANKA_API_KEY" \
  -F "file=@/path/to/any.png" | jq .

colcon test --packages-select franka_api_server --event-handlers console_direct+
```

**通过定义**：上述 curl 返回 200；controller 刚度路由在 `PAPER1_MODE=1` 时 **404 或未注册**；Fig.1 PDF 存在。
