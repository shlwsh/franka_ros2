## 2. AI 任务分解

### 2.1 paper1 LangGraph（主）

| 序 | 任务 | 路径 |
|----|------|------|
| 1 | `langgraph_router/state.py` | TypedDict：`q_img`, `flags`, `retry_count`, `route_decision`, `t_*`, `latency_ms` |
| 2 | `langgraph_router/routing.py` | `route(state, tau, K)` 三分支 |
| 3 | `langgraph_router/graph.py` | capture → edge_iqa → route → action |
| 4 | `tests/test_routing.py` | 单测覆盖三分支 |
| 5 | `langgraph_router/run.py` | CLI：`--trials N --api-base --log` |
| 6 | `sim/franka_bridge/client.py` | 完整：evaluate, skills, 计时 |
| 7 | Fig.2 | `figures/fig2_routing_flow.pdf` |

### 2.2 franka_ros2

| 序 | 任务 | 路径 |
|----|------|------|
| 1 | `scripts/paper1_closed_loop.sh` | 启栈 + 调 paper1 run |
| 2 | `scripts/validate_jsonl.py` | 字段 schema 校验 |
| 3 | Gazebo 或数据集 capture | `paper1_gazebo_capture.sh` 或复制 TCM 图到 `experiments/debug/` |

### 2.3 闭环一次 trial 数据流（冻结）

```
capture → POST /vision/evaluate → LangGraph route
  → resample: POST /motion/skills/go_to_* 
  → append JSONL
```
