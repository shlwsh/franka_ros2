## 4. 关键解读（快速样本，趋势参考）

1. **物理重采生效**：B2 的 M2 从旧版随机 uplift 的 **1.000** 降至 **0.625**，符合 SCI 改进方案「诚实报告」预期。
2. **B2 延迟最低**：M1 p50 ≈ 208 ms，优于 B3/B3t（~320–340 ms，含 CPU MobileNet）。
3. **B3 @ τ_B2 vs B3t @ τ_B3**：快速样本上 M2 同为 0.95；公平对比需看全量 + τ_B3 标定稳定性。
4. **B4 Hybrid**：M2=0.95，M1 介于 B2 与 B3 之间；全量 seeds 后再写进正文 Table III。
