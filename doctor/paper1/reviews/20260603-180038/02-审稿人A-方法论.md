## Major Issues

### METHOD-M1: 实验节过度碎片化，威胁 RA-L 篇幅与叙事

- **位置**: `latex/main.tex` L35–49；各 `05_*.tex`
- **证据**: Phase 0 统计 13 个实验 `\input`；`05_11_walkthrough.tex` 105 行、`05_7_implementation.tex` 101 行
- **问题**: 主文 Experiments 含 setup、双 TCM 节、B3、主结果、消融、讨论、扩展、实现、制品、部署、失败案例、walkthrough，编辑难以在 6–8 页内保留 Method+Experiments 核心。
- **建议**: 合并为「Setup + Main + Ablations + Discussion」四块；walkthrough/implementation/deployment 移附录或 Supplementary。

### METHOD-M2: 阈值 τ 在 setup 与主结果间表述冲突

- **位置**: `05_1_setup.tex` L5、L44；`05_4_tcm_validation.tex` L12；`table_ii.tex`；`recommended_tau.json`
- **证据**: setup 写 τ=**0.498**；`recommended_tau.json` → `"tau": 0.465`；主表 caption 写 τ_{B2}；Abstract 写 τ_{B2}=0.465
- **问题**: 读者无法判断 Table II 复现实验究竟用哪个 τ；影响可重复性与公平基线叙述。
- **建议**: 统一符号：τ_{full}=0.498、τ_{ROI}=0.465；setup 与 validation 各用一句定义；主表脚注标明 ROI τ。

### METHOD-M3: Discussion 出现与数据矛盾的“100%”表述

- **位置**: `05_5_discussion.tex` L56–57
- **证据**: `table_ii.json` B2 `m2_valid_rate` 三 seed 均值 **0.604**；L57 写 “into **100%** (B2)”
- **问题**: 属事实性错误，损害可信度。
- **建议**: 改为 0.604 或说明 “100% under latency model accounting for resampling” 并给出定义（若确有不同 M2 定义需单独指标名）。

### METHOD-M4: 缺少与经典/深度 IQA 的公平定量基线

- **位置**: `05_2_main_results.tex`；`04_1_edge_iqa.tex` Table `tab:iqa-compare`
- **证据**: 仅有定性对比表；无 NIQE/BRISQUE/无参考深度 IQA 在相同 τ 路由协议下的 M1/M2
- **问题**: 审稿人易质疑 “Edge-IQA 是否必要” 或 “B3 已足够”。
- **建议**: 至少增加 1 个轻量无参考 IQA（如 NIQE）+ 相同 LangGraph 壳的 Bx 行，或明确声明计算预算下不做并解释。
