## 4. 下载失败时已采用的措施

1. 先用 `cite_key_map.json` 和 `data/papers/*.pdf` 做本地匹配，避免重复下载。
2. 对候选 PDF 检查 `%PDF` 文件头，排除 HTML、登录页或下载失败占位文件。
3. 使用 `pdftotext` 抽取首页文本，与 BibTeX 题名 token 进行比对。
4. 对题名不匹配的候选文件不写入映射；例如旧的 `2012_Mittal_No-Reference_Image_Quality_Assessment_in_the_Spati.pdf` 未被认领为 BRISQUE。
5. 对 `wang2014edge` 的候选开放 PDF 做过尝试，但因标题匹配弱而未归档。
6. 对非论文网页引用 `opencv2020` 不再作为 PDF 下载目标处理。
