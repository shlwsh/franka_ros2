## T1–T10 — 投稿前专检（RA-L / RCIM）

> 细则见 [期刊投稿要点.md](期刊投稿要点.md)。若用户指定其他期刊，以用户目标覆盖本表。

| ID | 检查 | 触发问题 |
|----|------|----------|
| T1 | `main-ral.tex` / 目标期刊主稿存在且可编译，按 6 页目标、8 页上限审查 | 无投稿主稿、页数/模板不清或超 8 页 |
| T2 | IEEE/目标期刊格式、图表、参考文献规范 | 图表溢出、caption 不完整、bib 格式异常、PDF 字体问题 |
| T3 | 机器人自动采集贡献明确 | 稿件读起来像普通 IQA 或医学图像分类 |
| T4 | 双匿名、临床/TCM 声称、AI/COI 合规 | 暴露作者身份；未经验证却宣称诊断/疗效；声明缺失 |
| T5 | 复现材料完整 | 代码、数据、脚本、视频、硬件/网络条件不可追溯 |
| T6 | 中英稿同步 | 中文稿与英文稿数值、术语、图表不一致 |
| T7 | 投稿材料齐全 | Cover letter、CRediT、Data availability、PaperCept 信息缺失或旧版本 |
| T8 | R&R 产物准备 | 需要修改重投时缺 30 天计划、Author Response 或 Diff 稿 |
| T9 | 摘要/标题/关键词 | 摘要过长/过短、标题泛、关键词少或机器人相关性弱 |
| T10 | 多媒体 | 视频/代码/数据无法支撑主文，或用补充文本规避页数 |

## 推荐预检命令

```bash
PAPER1_ROOT=doctor/paper1
find "$PAPER1_ROOT/experiments/results" -maxdepth 1 -name '*.json' -print | sort
grep -c '\\input{sections/05' "$PAPER1_ROOT/latex/main.tex"
grep -c '\\paragraph' "$PAPER1_ROOT/latex/sections/05_5_discussion.tex"
grep -Ei 'faq|reviewer faq|todo|待填' "$PAPER1_ROOT/latex" "$PAPER1_ROOT/submission" 2>/dev/null || true
python3 "$PAPER1_ROOT/scripts/check_paper1_refs.py"
python3 "$PAPER1_ROOT/scripts/paper1_audit_papers.py"
```
