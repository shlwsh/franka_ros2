# 参考文献归档细则

> **规则**：正文 `\cite{}` 的关键文献必须可核实，并尽量归档至 `{PAPER1_ROOT}/data/papers/`。
> **负责角色**：Phase 1 预检 + Phase 2 伦理审查。
> **当前 Paper I 入口**：`doctor/paper1/scripts/paper1_audit_papers.py`、`doctor/paper1/data/papers/cite_audit.json`。

---

## 1. 通过标准

| 层级 | 要求 |
|------|------|
| **bib 完整性** | 正文 cite key 均存在于 `latex/references.bib` |
| **可核实性** | DOI、arXiv、出版社 URL 或稳定项目页可解析；关键引用不得只有不可追溯标题 |
| **归档** | 核心引用在 `data/papers/` 有 PDF、HTML 快照或元数据索引 |
| **真实性** | 本地 PDF 标题、作者、年份与 bib key 对应；不得用错论文顶替 |
| **清单** | `cite_audit.json` / `papers_index.json` 能解释缺失项与处理计划 |

---

## 2. 自动化命令（审核优先运行）

```bash
PAPER1_ROOT=doctor/paper1

# label/ref 基本一致性
python3 "$PAPER1_ROOT/scripts/check_paper1_refs.py"

# RA-L 引用与本地 papers/ 归档审计
python3 "$PAPER1_ROOT/scripts/paper1_audit_papers.py"

# 查看审计摘要
python3 - <<'PY'
import json, pathlib
p = pathlib.Path("doctor/paper1/data/papers/cite_audit.json")
if p.exists():
    d = json.loads(p.read_text())
    print("ral_cite_count", d.get("ral_cite_count"))
    print("with_pdf", d.get("ral_cites_with_local_pdf"))
    print("without_pdf", d.get("ral_cites_without_local_pdf"))
else:
    print("missing", p)
PY
```

若项目移植后存在 `scripts/verify_cited_papers.py`，可补充运行：

```bash
python3 scripts/verify_cited_papers.py --download
```

## 3. 归档类型说明

| 类型 | 含义 | 典型路径 |
|------|------|----------|
| PDF | 开放论文或作者自存档 | `data/papers/2023_Wang_Exploring_CLIP_*.pdf` |
| HTML 快照 | 官网、文档、出版社摘要页 | `data/papers/web_snapshots/*.html` |
| 元数据 JSON | CrossRef / arXiv / OpenAlex 等元数据 | `data/papers/web_snapshots/*_metadata.json` |
| 索引条目 | 已下载 PDF 的题名、作者、DOI、文件名 | `data/papers/papers_index.json` |

闭源论文不要求必须取得 PDF，但必须能说明 DOI/URL 已核实，并保留元数据或网页快照。

---

## 4. 预检检查项 C3 / H5

| ID | 严重性 | 检查 | 验收 |
|----|--------|------|------|
| C3a | P0 | cite key 均在 bib 中 | 编译/脚本无 undefined citation |
| C3b | P0/P1 | 核心文献 DOI/URL 有效 | bib 中关键工作有 DOI、arXiv 或稳定 URL |
| C3c | P1 | RA-L cite 有本地 PDF 或快照 | `cite_audit.json` 缺失项有处理说明 |
| C3d | P0 | PDF 与 bib key 对应 | 审计无 WRONG_PAPER 或明显题名不符 |
| C3e | P2 | 新增引用后重跑审计 | `cite_audit.json` 时间戳更新 |

---

## 5. 新增文献工作流

1. 在 `latex/references.bib` 添加条目，优先真实 DOI / arXiv / publisher URL。
2. 正文添加 `\cite{key}` 后运行 `check_paper1_refs.py` 与 `paper1_audit_papers.py`。
3. 若审计缺 PDF：下载开放 PDF 或保存官网/出版社/DOI 元数据快照。
4. 更新 `data/papers/cite_key_map.json` 或 `papers_index.json`，让 cite key 与本地文件可追溯。
5. 改稿报告中记录新增引用目的、替换原因和归档状态。

---

## 6. 审核产出要求

Phase 1 `01-预检报告.md` 须含 **C3 参考文献与归档** 小节：

```text
RA-L cited: 11 | with local PDF: 6 | without PDF: 5 | script: paper1_audit_papers.py
主要缺失: chitta2009moveit, mittal2012niqe, ...
处理建议: 下载开放 PDF / 保存 DOI 元数据快照 / 更新 cite_key_map.json
```

Phase 5 `05-全面评审报告.md` 附录引用 `data/papers/cite_audit.json`，并将无法核实的核心引用列入 P0/P1 行动清单。
