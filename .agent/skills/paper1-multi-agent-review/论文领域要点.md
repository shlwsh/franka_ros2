| 代号 | 问题 |
|------|------|
| **SQ1** | 边缘能否在实时约束下可靠筛除低质量上行？ |

## 三条贡献（投稿表述）

1. **架构**：IQA 下沉边侧网关，闭环内过滤无效上行。
2. **算法**：基于 $Q_{img}$ 与 $\tau$ 的 Confidence-Aware Routing（LangGraph，可日志复现）。
3. **验证**：TCM-Tongue 主实验 + 跨集/仿真辅轨；相对 B0–B3；FR3 假硬件闭环演示。

**审稿要求**：三贡献必须在 Abstract、Introduction、Method、Conclusion 中以相同逻辑贯穿；若只在某一节出现，按 `C10` 或 `DOMAIN-D9` 报告。
